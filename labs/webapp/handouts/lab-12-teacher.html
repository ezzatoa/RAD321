1. Opening briefing (10–12 minutes)

  1. Connect the simulation variables to Elements of Digital Image Quality.
  2. Explain that the virtual workstation phantom renders multi-tissue attenuation, an active histogram passband with clipping zones, and the Look-Up Table (LUT) transfer characteristic.
  3. Demonstrate how narrowing Window Width increases LUT slope/contrast gain, and how shifting Window Level targets specific anatomical densities.
  4. Emphasize that automatic rescaling masks overexposure on the monitor, making Deviation Index (DI) monitoring vital to prevent dose creep.

3. Expected experimental trend

  1. Predict the visual and quantitative effect of narrowing window width.
  2. Record a standard mediastinum baseline (WW: 400, WL: 40, EI: 100).
  3. Narrow window width (WW: 120, WL: 45) and record higher contrast gain (2.13 gray/HU) and lesion CNR, noting fat and bone clipping.
  4. Explore bone detail (WW: 1500, WL: 400) or underexposure/noise (EI: 55, DI: −2.6) for a third run.
  5. Compare display range, contrast gain, CNR, and dose warning.

4. Clinical scenario key

Prompt: During a routine audit of portable chest radiographs, all images appear visually crisp with normal brightness, but 40% of cases exhibit Exposure Index (EI) values corresponding to a Deviation Index (DI) above +2.5. What is the correct professional action?

Best response: Investigate exposure technique charts and calibrate AEC/manual factors to prevent dose creep, recognizing that digital processing masks overexposure.

Rationale: Digital processing automatically rescales image brightness to look acceptable, masking overexposure. An elevated Deviation Index (+2.5 DI represents an exposure ~78% above target) indicates dose creep requiring immediate technique review.

5. Knowledge-check key

1. Decreasing window width (narrow window) produces:
Higher displayed contrast over a smaller range of pixel values — A narrower window width maps fewer pixel values across the entire 0–255 display grayscale, resulting in a steeper LUT slope and higher displayed contrast within that range.
2. Window Level (WL) controls the:
Center (midpoint) of the displayed gray-value range, controlling image brightness — Window Level is the midpoint value of the display window. Shifting WL shifts the center of the grayscale curve, determining which anatomical tissue density is rendered as mid-gray.
3. Increasing window level while keeping window width constant causes the displayed image to appear:
Overall darker, because higher pixel values are required to achieve mid-gray — Increasing Window Level shifts the display window toward higher HU values. Consequently, previous mid-level tissues fall below the window center and appear darker.
4. Wide digital exposure latitude combined with automatic rescaling can lead to:
Exposure creep, because overexposed images appear visually acceptable while delivering excess patient dose — Because digital processing automatically normalizes image brightness, overexposed radiographs do not appear excessively black as film did. This masks overexposure unless Exposure Index (EI/DI) is monitored.
