1. Opening briefing (10–12 minutes)

  1. Connect the simulation variables to Fluoroscopy.
  2. Explain that the visual is a teaching model; numerical trends and formulas matter more than decorative appearance.
  3. Demonstrate one baseline run without revealing the required comparison.
  4. Require one-variable-at-a-time changes and references to run numbers in written answers.

3. Expected experimental trend

  1. Predict how operator distance changes scatter dose.
  2. Record a normal-field baseline.
  3. Reduce field size to simulate magnification mode and record a second run.
  4. Increase distance and shielding for a third run.
  5. Compare patient dose-rate and operator dose indices.

4. Clinical scenario key

Prompt: A small structure requires fluoroscopic magnification. Which action best manages the dose trade-off?

Best response: Use magnification only when needed, pulse/time-limit, collimate, and protect staff

Magnification mode usually increases dose rate; limit its time and combine collimation, distance, and shielding.

5. Knowledge-check key

When an image-intensifier system enters magnification mode, the typical effect is:
Smaller field and higher dose rate — Magnification mode uses a smaller active field and typically increases dose rate to maintain brightness.
The photocathode converts:
Light into electrons — In an image intensifier, the photocathode converts entrance-phosphor light to electrons.
Magnification mode typically uses:
A smaller input field and higher dose rate — A smaller active field requires more input to maintain brightness.
Doubling operator distance from a point scatter source ideally reduces intensity to:
One quarter — The inverse-square relationship gives one quarter at double distance.

6. Grading and final-exam preparation

  • Simulation credit requires 3 unique settings, not a completion click.
  • Give calculation/interpretation credit only when the student cites the run evidence.
  • Use the clinical response and critical-thinking worksheet item as practical-final preparation.
  • The self-rubric is advisory; the instructor assigns the official score from the exported evidence.
